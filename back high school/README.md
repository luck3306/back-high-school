# 重回高中

一款从高一开学出发的中文文字剧情游戏。每局随机生成五名核心同学，经历关系主线、随机校园事件、概率分班与突发事件，最终走向 22 种不同结局。

当前版本是无图片、可开关程序化背景音乐、零第三方依赖的可游玩浏览器版。

## 启动游戏

需要 Node.js 20 或更高版本。

```powershell
npm start
```

默认地址：

```text
http://127.0.0.1:4173
```

## 已实现内容

- 高一至高三共六个学期，完整三年流程。
- 姓名、性别自定义；玩家选择学业起点与兴趣方向。
- 每局随机生成五名核心人物：
  - 姓名不重复。
  - 从学业、艺术、体育、组织、音乐/游离五类身份中抽取。
  - 身份池内部随机具体角色。
  - 五人性格互不重复。
  - 性别固定配置为两女三男，并在人物档案中明确展示。
- 五个核心人物第一次出现时会逐一出场，展示姓名、性别、身份、性格、第一印象和初见剧情。
- 家庭背景与隐藏特质随机生成，可重掷一次。
- 不再有主角隐藏性格，也没有性格数值判定。
- 每学期包含 5 个事件场景：
  - 2 个常规剧情。
  - 1 个关系主线，优先涉及当前羁绊较高的三名角色。
  - 1 个双角色交叉关系事件。
  - 1 个突发事件。
- 单周目共 30 个事件场景加 6 个章节场景。
- 高一下学期结束触发概率分班：
  - 根据选择与家庭背景产生 35%–90% 的分班概率。
  - 分班后保证至少一名核心同学同班、至少两名分到其他班级。
  - 同班与跨班拥有不同事件和恋爱场景。
- 事件池共 115 个事件：
  - 15 个角色关系主线。
  - 10 个双角色交叉关系事件。
  - 10 段新增五角色恋爱事件。
  - 4 段男女主专属剧情。
  - 8 段分班专属剧情。
  - 12 个突发事件及其他校园、家庭、社团事件。
- 每个事件至少 3 个选择，关系与恋爱事件提供更具体的角色反馈。
- 恋爱事件包含男女主不同文本。
- 五人全部可以发展恋爱或友情路线。
- 22 个结局：5 个恋爱、5 个友情、3 个成长、5 个群像、4 个高光结局。
- 毕业页展示结局、家庭背景、隐藏特质、分班结果、五人最终关系与三年高光记录。
- 程序化 Web Audio 背景音乐：标题、日常、恋爱、突发事件、毕业五套主题。
- 右上角音乐开关会保存设置。
- 自动存档、继续游戏、结局图鉴和未解锁线索。
- 纯文字响应式界面，无生成图片，适配桌面和手机竖屏。

## 常用命令

```powershell
npm start        # 启动本地游戏服务器
npm test         # 运行规则、流程、分班、结局和存档测试
npm run check    # 校验剧情、家庭专属事件、突发事件与结局
npm run simulate # 自动游玩 10,000 个周目并输出结局分布
```

浏览器端完整冒烟测试：

```powershell
node scripts/browser-smoke.mjs
```

测试需要 Microsoft Edge。截图输出到 `test-artifacts/`。

## 剧情维护

事件数据位于 `src/content/events/`。常用字段：

- `id`、`category`、`title`、`chapters`、`weight`。
- `npc`：关联的内部角色槽位，例如 `arts`、`academic`、`sports`、`leadership`、`music`。
- `relationship: true`：每学期关系主线事件。
- `crossCharacter: true`：双角色交叉事件。
- `surprise: true`：每学期必抽的突发事件。
- `classState: "split" | "same"`：分班触发后或保留原班时可用。
- `playerGenders`：限定男主或女主的事件。
- `textByGender`：同一事件按主角性别显示不同正文。
- `familyArc` 与 `families`：家庭背景专属事件。

人物姓名、身份和性格通过 `{arts.name}`、`{npc.name}`、`{npc.identity}`、`{npc.personality}` 等占位符写入剧情。

修改剧情后运行：

```powershell
npm run check
npm test
```

## 存档

- 当前进度保存在浏览器 `localStorage`，存档版本为 v3。
- 每个事件结果写入后自动保存。
- 结局图鉴保存当次随机阵容、分班结果和已渲染结局文本。
- 隐私模式或禁用本地存储时，游戏会退回当前页面内存存档。

## TapTap 与微信小游戏状态

当前机器未安装 Cocos Creator、Android SDK 和微信小游戏构建工具，因此交付的是可直接游玩的浏览器版，尚未生成 TapTap APK 或微信小游戏包。

剧情数据、规则引擎和 DOM 界面已经分离。迁移 Cocos 时可直接复用 `src/config.js`、`src/engine.js` 和 `src/content/`，仅需重建渲染层、音频平台适配和存储适配。

## 设计边界

- 仅简体中文。
- 无联网、账号、排行榜、插画和多语言。
- 不使用中途失败或强制游戏结束；低属性会改变事件和结局，但不会提前终止周目。
